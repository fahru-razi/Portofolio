schedule_interval = '0 0 * * *'

  4. 4

    Hitung polarity dengan TextBlob

    Task sa_load membaca semua berita di koleksi, lalu TextBlob menghitung polarity dari summary tiap berita, dari −1 sampai +1. Metode ini hanya untuk teks bahasa Inggris.

    analysis = TextBlob(self.text)
analysis.sentiment.polarity  # −1 … +1

    Beri label dan susun DataFrame

    Polarity di atas 0 diberi label positive, tepat 0 neutral, dan di bawah 0 negative. Hasilnya dikumpulkan menjadi DataFrame pandas berkolom text dan sentiment.
